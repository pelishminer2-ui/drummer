Cool Imports — Drummer Studio
==============================

Drop your own WAV, MP3, and MIDI files here (or run Import-Cool-Imports.ps1).

Folders:
  Kits/     — one-shot drum WAVs (folder kit, like Pack Punk)
  Loops/    — audio loops (WAV/MP3)
  Grooves/  — MIDI grooves
  Inbox/    — optional staging folder for Import-Cool-Imports.ps1

Note: XLN Addictive Drums .xpak files cannot be imported — they are a locked
plugin format. Export WAV from your DAW/plugin, then import those files here.
