WHAT IT CAN DO
--------------
- Play drum kits - click the kit photo or use keyboard (Space kick, F snare, etc.)
- Browse and play MIDI grooves and audio loops (Grooves tab)
- Mixer with faders, pan, and presets (Default, Roomy, Dry)
- Match your music to library grooves:
    - Record Guitar (5s built-in metronome count-in, then mic capture)
    - Import Track (WAV / MP3 / FLAC / OGG from disk)
    - Match Selected (pick a loop in Grooves or Ass Kickers)
  Results appear on the Matches Found tab - drag into Audacity or your DAW
- Ass Kickers - demo tracks with genre filter
- Selected Tracks - pin favorites from the active library
- Open in Audacity after recording (optional)
- Kit lights up with the groove during playback

LIBRARIES (local - not all included in git)
-------------------------------------------
Run Import-Libraries.ps1 for kits and grooves you own.

Optional loop packs (download MP3s locally):
  .\Import-Monkey-Alts.ps1    - 14 alt-rock loops
  .\Import-Metal-Hitters.ps1  - 27 metal loops
  .\Import-Stream-Loops.ps1     - both loop packs (one command)
  .\Import-Cool-Imports.ps1   - your WAV/MP3/MIDI drop folder
  .\Import-MT-Wild-Drums.ps1    - MT Power Drum Kit from Downloads zip
  .\Import-SSD-Demos.ps1        - Ass Kickers demo MP3s

Libraries live under:
  Libraries\ (next to this file; pass -LibRoot or -Root to import scripts
  to target a different drive/location instead)

Note: XLN Addictive Drums .xpak files cannot be imported - export WAV
from your plugin/DAW and use Cool Imports instead.

INSTALL & RUN
-------------
  .\Install Drummer Studio.ps1

Or run portable (keep the whole Windows 11 folder - includes _internal):
  Windows 11\Drummer Studio.exe

SOURCE & BUILD
--------------
  pip install -r source\requirements.txt
  python source\drummer_app.py

  cd source
  .\build_installer.ps1

See README.md and CHANGELOG.md for full details.
